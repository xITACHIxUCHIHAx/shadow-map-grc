Managed Integration Details

  1. Shadow Map GRC detects or installs its managed local OWASP ZAP instance.
  2. Shadow Map GRC generates and stores the ZAP API key internally.
  3. The application starts ZAP in daemon mode and verifies its local API connection.
  4. Existing alerts can be retrieved and imported into GRC draft findings.
  5. Review draft findings before accepting them into your GRC records.
Security boundary: The integration uses a local ZAP API endpoint. Connection checks and alert retrieval do not start scans. Scanning remains an explicit action through the authorized assessment workflow.
